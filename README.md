# rust_iced_helloworld
Iced (https://github.com/iced-rs/iced) is a GUI framework for Rust. I don't own it. 

I wanted to play with iced, and I needed a known-good "Hello World" project to explore its features. 

I asked Claude to write a Hello World demonstration of iced features. This is it.

BUILD:
Cargo's built-in commands work as expected:
- cargo run
- cargo build --release

On MacOS: MacBook M1 Max
